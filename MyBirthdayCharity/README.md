# MyBirthdayCharity

React website for the MyBirthdayCharity NGO, built with Vite and pure CSS.

The current hero photo uses a free Pexels image as a placeholder. Replace it
with your own foundation photo when the WordPress content is migrated.

## Run locally

```bash
npm install
npm run dev
```

## Available scripts

- `npm run dev` starts the local development server.
- `npm run build` creates a production build.
- `npm run preview` serves the production build locally.
